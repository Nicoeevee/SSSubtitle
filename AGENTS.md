# SSSubtitle Agent Guide

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `Nicoeevee/SSSubtitle`. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role triage vocabulary is used. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain-document layout. See `docs/agents/domain.md`.

### Rust subtitle workflow deepening

Before changing Rust subtitle search, Candidate ranking or projection, Preview pagination or caching, Acquisition, the subtitle FRB interface, or their Flutter adapter and tests, read `docs/agents/subtitle-workflow-deepening.md`. It is the accepted replacement plan and completion gate for that work.
