# SSSubtitle 用户指南

## 支持范围

SSSubtitle 面向桌面端与 Web。当前持续开发和验证 Windows 与 Web；仓库保留 Linux 与 macOS 的桌面工程壳，但它们不属于当前发布验证范围。Android 与 iOS 支持已经移除，不再提供相应工程、构建或依赖验证。

当前字幕来源使用未公开、无稳定性保证的第三方接口。服务方接口、返回格式或可用性发生变化时，搜索和下载可能暂时不可用。

## 基本流程

1. 使用系统文件选择器选择视频。
2. 检查自动生成的搜索名，并在需要时手动修改。
3. 执行搜索，使用候选列表查看语言、格式、评分和匹配理由。
4. 首次选择候选时按需下载字幕；后续预览从内存缓存读取。
5. 打开平台保存对话框并确认文件名和位置。

自动搜索名会先去掉最后一个扩展名；如果名称中包含 `@`，则使用最后一个 `@` 后面的非空部分。

保存时，建议使用原视频的完整基名并只替换字幕扩展名。应用会以该名称作为默认值，不会将第三方候选名写入保存文件名。将字幕保存在视频同一目录后，播放器通常可以按同名规则自动索引。

## 键盘操作

- `↑` / `↓`：切换字幕候选
- `←` / `→`：切换当前字幕预览的上一页或下一页
- `Home` / `End`：跳到候选列表首项或末项
- `PageUp` / `PageDown`：在候选列表中快速移动
- `Enter`：保存当前字幕
- `Esc`：取消

预览每页显示 30 行。切换候选后，预览会回到第一页。

## 字幕格式与编码

- 支持 SRT、ASS、SSA 和 VTT。
- 支持 UTF-8、UTF-8 BOM、UTF-16LE、UTF-16BE，并对旧中文字幕提供 GBK/CP936 回退。
- 会拒绝 HTML、JSON、空内容、过短内容以及超过 20 MiB 的字幕响应。

## 安全与隐私

- 搜索请求只发送用户确认后的搜索名；视频内容不会上传。
- 搜索名通过 HTTPS GET 查询参数传输，可能出现在服务方、代理或浏览器的网络诊断记录中。应用本身不记录搜索名；如有严格隐私要求，请先改用不含敏感信息的别名。
- 下载地址保留在 Rust 进程内的有界注册表中，Flutter 只接收不透明候选 ID。
- 字幕默认保存名沿用用户选择的视频基名，不使用第三方候选名称；保存完成提示不显示本地绝对路径，已下载字节随后会从 Flutter 内存缓存中移除。
- 原生下载只允许 HTTPS 标准端口和受信任提供方域名，并限制重定向次数。
- 搜索响应上限为 2 MiB；字幕响应超过 20 MiB 时会停止读取。
- SHA-1 CID 只用于兼容第三方内容标识，不能视为安全完整性证明。

## 当前边界

- 视频范围读取、CID 计算和可选时长尚未接入界面；当前排序主要依据名称、语言、格式和服务方评分。
- 不计算 GCID。
- Web 受浏览器安全模型约束：无法设置浏览器禁止的请求头，也依赖服务方和字幕 CDN 的 CORS 响应。必要时只能使用自有、域名白名单受限的中继服务。
- 当前没有批量扫描、目录监视、字幕编辑、翻译、同步或嵌入字幕提取。
