# Keep platform capabilities in Flutter and subtitle decisions in Rust

SSSubtitle uses Flutter for presentation and platform-owned capabilities such as picking video data and saving or exporting a Subtitle Artifact, while Rust owns video fingerprinting, provider protocols, normalization, ranking, validation, decoding, and preview pagination behind a narrow `flutter_rust_bridge` boundary. This avoids transferring whole videos across the bridge, keeps provider changes out of the UI, and permits one business path across desktop and Web; current release validation targets Windows and Web, while Android and iOS are unsupported. Web may require an allowlisted relay when a provider does not permit browser CORS, and saving remains a platform-specific operation rather than an assumption that every platform can write beside the video.
